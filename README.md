# OKOK ADV BIA Scale (adv_bia_scale)

Home Assistant custom integration for Bluetooth BIA (Bioelectrical Impedance Analysis) scales that use the OKOK protocol (manufacturer ID 8394 / 0x20CA).

Supports real-time body composition measurements via passive BLE advertisement monitoring — no active Bluetooth connection required.

# Релиз 2.0 — Мульти-профиль

Добавлена поддержка **нескольких пользователей** с **автоопределением по весу**:
- Каждый пользователь задаёт диапазон веса (мин–макс)
- При измерении весы автоматически определяют профиль по ближайшему совпадению
- Каждый пользователь получает отдельный набор сенсоров с индивидуальными BIA-расчётами
- Управление профилями через **Настройки → Устройства → OKOK ADV BIA Scale → Настроить**

## Сенсоры для каждого профиля

- Вес, Импеданс, ИМТ, Жировая масса, Мышечная масса, Масса костей, Вода
- Висцеральный жир, Базовый обмен, Метаболический возраст
- Протеины, Масса без жира, Подкожный жир, Пульс

### Настройка профилей

Каждый профиль включает:
- Имя пользователя
- Рост (см)
- Дата рождения (DD.MM.YYYY) — возраст считается автоматически
- Пол
- Уровень активности
- Диапазон веса (мин–макс, кг) — для автоопределения

# Установка

## HACS (рекомендуется)

1. Добавьте этот репозиторий в HACS:
   - HACS → Интеграции → ⋮ → Пользовательские репозитории
   - URL: `https://github.com/ваш-username/adv_bia_scale`
   - Категория: Integration
2. Найдите "OKOK ADV BIA Scale (Multi-Profile)" и установите
3. Перезапустите Home Assistant

## Вручную

1. Скопируйте каталог `custom_components/adv_bia_scale/` в `custom_components/` вашей конфигурации HA
2. Перезапустите Home Assistant

# Настройка

1. **Настройки** → **Устройства и службы** → **Добавить интеграцию**
2. Найдите **OKOK ADV BIA Scale (Multi-Profile)**
3. Шаг 1: укажите MAC-адрес и название устройства
4. Шаг 2: заполните данные первого пользователя (рост, дата рождения, пол, активность, диапазон веса)
5. После добавления можно добавлять/редактировать/удалять профили через **Настроить**

# Требования

- **Bluetooth** интеграция в HA должна быть настроена и работать
- BLE-адаптер должен видеть advertisement от весов (manufacturer 8394)
- Весы OKOK с поддержкой BIA
